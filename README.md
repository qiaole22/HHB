# Haushaltsbuch (PWA)

## Einrichtung
1. Repo auf GitHub anlegen, alle Dateien hochladen, Settings → Pages → *Deploy from a branch* → `main` / root.
2. App öffnen (`https://DEINNAME.github.io/REPO/`) → auf ⟳ tippen → „Token erstellen“ → „Generate token“ → kopieren → einfügen → „Verbinden“. Die App legt das private Daten-Repo `haushaltsbuch-daten` selbst an.
3. Zweites Gerät: ⚙ → „Anderes Gerät koppeln“ → Link dorthin schicken und öffnen. Fertig.

Danach genügt ein Tipp auf ⟳ (automatisch passiert es beim Öffnen und nach jeder Buchung).
